# Study Compiler v1.5

시험범위와 교재 버전을 입력하면, 개념별 학습 태스크를 만들고 **D-day 기반으로 자동 분배**해 주는 GitHub Pages 호환 정적 웹앱입니다.

v1.5는 v0.9의 입력/AI/수행평가 기능을 유지하면서, 다음 기능을 추가했습니다.

## v1.5 핵심 기능

- 과목/시험일/과목 유형 입력
- 시험범위 트리 입력
  - `ㄴ` 개수 또는 들여쓰기로 계층 표현
- 교재 버전 입력
  - 예: `v0: 개념서`, `v1: 기본 유형서`, `v2: 중난도 유형서`, `v3: 심화서`
- **개념 × 버전 태스크 자동 생성**
- **시험일까지 남은 날짜를 기준으로 버전별 학습 기간 자동 분배**
- **오늘의 빌드 화면**
- **이번 주 보기 화면**
- 수행평가 p0~p4 단계 관리
- 수행평가 마감일 주간 보기 표시
- 완료 체크 및 localStorage 저장
- AI 설계 프롬프트 생성
- AI JSON 붙여넣기 및 검토/적용
- 백업 내보내기/가져오기

## 기존 데이터 유지

v1.5는 v0.9와 같은 localStorage 키를 사용합니다.

```txt
study_compiler_v09
```

따라서 같은 브라우저에서 v0.9를 사용하던 경우, v1.5에서도 기존 과목/태스크/수행평가 데이터가 이어질 수 있습니다.

## 실행 방법

1. ZIP 압축을 풉니다.
2. GitHub Pages에 업로드하거나 로컬 서버로 실행합니다.
3. JS 모듈 구조이므로 파일 더블클릭보다 GitHub Pages/로컬 서버 실행을 권장합니다.

간단 로컬 서버 예시:

```bash
python -m http.server 8000
```

그 후 브라우저에서 `http://localhost:8000` 접속.

## 추천 사용 흐름

1. `과목/범위` 탭에서 과목을 추가합니다.
2. 시험일과 과목 유형을 설정합니다.
3. 시험범위 트리를 입력합니다.
4. 교재 버전을 입력합니다.
5. `태스크 생성/재생성`을 누릅니다.
6. `오늘의 빌드`에서 오늘 할 일을 확인합니다.
7. `이번 주 보기`에서 한 주 배치를 확인합니다.
8. 완료한 태스크를 체크합니다.

## D-day 기반 자동 분배 방식

v1.5 스케줄러는 다음 순서로 작동합니다.

```txt
오늘 날짜 → 시험일 사이 날짜 생성
버전 수에 따라 날짜 구간 분리
v0, v1, v2, v3 태스크를 각 구간에 배치
하루 가능 시간의 약 70%를 정규 학습 용량으로 사용
```

예를 들어 시험까지 4주, 버전이 v0~v3라면:

```txt
1구간: v0 개념서
2구간: v1 기본 유형서
3구간: v2 중난도 유형서
4구간: v3 심화서
```

## 수행평가 단계

- `p0`: 요구사항 확인
- `p1`: 자료조사
- `p2`: 초안
- `p2.5`: 수정/피드백 반영
- `p3`: 최종본
- `p4`: 제출

수행평가는 오늘의 빌드에는 다음 미완료 단계가 표시되고, 이번 주 보기에는 마감일이 표시됩니다.

## 설계 원칙

- 사용자가 시험범위와 교재를 직접 입력합니다.
- AI는 구조화 보조만 합니다.
- 앱은 입력된 데이터를 바탕으로 태스크를 생성합니다.
- 완료 기준은 “봤다”보다 “수행 가능하다”에 맞추는 것을 권장합니다.
- v1.5는 자동 재편성 전 단계입니다. 먼저 날짜 배치와 주간 보기가 안정적으로 작동하는지 확인하는 것이 목표입니다.
