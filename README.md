# Study Compiler v2.5

시험범위와 교재 버전을 입력하면, 개념별 학습 태스크를 만들고 **D-day 기반 자동 분배 + R1/R2/R3 복습 + n.5 오답 패치**까지 관리하는 GitHub Pages 호환 정적 웹앱입니다.

v2.5는 v1.5의 D-day/오늘/주간 보기 기능을 유지하면서, 학습 효과 핵심층을 추가했습니다.

## v2.5 핵심 기능

- 과목/시험일 입력
- 시험범위 트리 입력
  - `ㄴ` 개수 또는 들여쓰기로 계층 표현
- 교재 버전 입력
  - 예: `v0: 개념서`, `v1: 기본 유형서`, `v2: 중난도 유형서`, `v3: 심화서`
- 개념 × 버전 태스크 자동 생성
- 시험일까지 남은 날짜를 기준으로 버전별 학습 기간 자동 분배
- 오늘의 빌드 화면
- 이번 주 보기 화면
- 수행평가 p0~p4 단계 관리
- 수행평가 마감일 주간 보기 표시
- 학습 기록 입력
  - 실제 소요 시간
  - 정답률
  - 이해도
  - 메모
- 암기형/혼합형 과목 완료 시 R1/R2/R3 복습 자동 생성
- 정답률/이해도 기준 n.5 오답 패치 생성
- 패치 태스크 우선순위 반영
- 완료 체크 및 localStorage 저장
- AI 설계 프롬프트 생성
- AI JSON 붙여넣기 및 검토/적용
- 백업 내보내기/가져오기

## 기존 데이터 유지

v2.5는 v0.9/v1.5와 같은 localStorage 키를 사용합니다.

```txt
study_compiler_v09
```

따라서 같은 브라우저에서 v0.9/v1.5를 사용하던 경우, v2.5에서도 기존 과목/태스크/수행평가 데이터가 이어질 수 있습니다.

## 실행 방법

1. ZIP 압축을 풉니다.
2. GitHub Pages에 업로드하거나 로컬 서버로 실행합니다.
3. JS 모듈 구조이므로 파일 더블클릭보다 GitHub Pages/로컬 서버 실행을 권장합니다.

간단 로컬 서버 예시:

```bash
python -m http.server 8000
```

그 후 브라우저에서 `http://localhost:8000` 접속.

## 추천 사용 흐름

1. `과목/범위` 탭에서 과목을 추가합니다.
2. 시험일과 과목 유형을 설정합니다.
3. 시험범위 트리를 입력합니다.
4. 교재 버전을 입력합니다.
5. `태스크 생성/재생성`을 누릅니다.
6. `오늘의 빌드`에서 오늘 할 일을 확인합니다.
7. 실제 시간/정답률/이해도를 입력합니다.
8. 완료 체크를 누르면 조건에 따라 복습/패치가 자동 생성됩니다.

## R1/R2/R3 복습 규칙

암기형(`memory`) 또는 혼합형(`mixed`) 과목에서 `study` 태스크를 완료하면 자동으로 복습이 생성됩니다.

```txt
R1: 완료 다음날
R2: 완료 3일 뒤
R3: 완료 7일 뒤
```

복습은 오늘/주간 보기에 `review` 배지로 표시됩니다.

## n.5 오답 패치 규칙

학습 기록에서 다음 중 하나에 해당하면 패치가 생성됩니다.

```txt
정답률 80% 미만
또는 이해도 3/5 이하
```

예시:

```txt
v1 완료, 정답률 65%
→ v1.5 오답 패치 생성
```

패치 태스크는 우선순위가 높아 오늘/주간 보기에서 먼저 표시됩니다.

## 수행평가 단계

- `p0`: 요구사항 확인
- `p1`: 자료조사
- `p2`: 초안
- `p2.5`: 수정/피드백 반영
- `p3`: 최종본
- `p4`: 제출

수행평가는 오늘의 빌드에는 다음 미완료 단계가 표시되고, 이번 주 보기에는 마감일이 표시됩니다.
