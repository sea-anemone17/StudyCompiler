# Study Compiler v0.9

시험범위와 교재 버전을 입력하면, 개념별 학습 태스크를 만들고 오늘의 빌드로 보여 주는 GitHub Pages 호환 정적 웹앱입니다.

## 핵심 기능

- 과목/시험일/과목 유형 입력
- 시험범위 트리 입력
  - `ㄴ` 개수 또는 들여쓰기로 계층 표현
- 교재 버전 입력
  - 예: `v0: 개념서`, `v1: 기본 유형서`, `v2: 중난도 유형서`, `v3: 심화서`
- 개념 × 버전 태스크 자동 생성
- D-day 기준 간단 날짜 배치
- 오늘의 빌드 화면
- 완료 체크 및 localStorage 저장
- AI 설계 프롬프트 생성
- AI JSON 붙여넣기 및 검토/적용
- 수행평가 p0~p4 단계 관리
- 백업 내보내기/가져오기

## 실행 방법

1. ZIP 압축을 풉니다.
2. `index.html`을 브라우저로 엽니다.
3. GitHub Pages에 올릴 경우 저장소 루트에 파일을 그대로 업로드하면 됩니다.

## 추천 사용 흐름

1. `과목/범위` 탭에서 과목을 추가합니다.
2. 시험일과 과목 유형을 설정합니다.
3. 시험범위 트리를 입력합니다.
4. 교재 버전을 입력합니다.
5. `태스크 생성/재생성`을 누릅니다.
6. `오늘의 빌드`에서 오늘 해야 할 일을 확인하고 완료 체크합니다.

## AI 설계 모드

1. 과목/범위를 입력한 뒤 `AI 설계` 탭으로 이동합니다.
2. `프롬프트 만들기`를 누릅니다.
3. 생성된 프롬프트를 AI에게 붙여넣습니다.
4. AI가 JSON을 출력하면 앱의 `AI JSON 붙여넣기 및 검토` 칸에 붙여넣습니다.
5. `검토` 후 `적용`합니다.

## 수행평가 단계

- `p0`: 요구사항 확인
- `p1`: 자료조사
- `p2`: 초안
- `p2.5`: 수정/피드백 반영
- `p3`: 최종본
- `p4`: 제출

## v1 이후 확장 슬롯

다음 파일은 v0.9에서 확장 슬롯으로 포함되어 있습니다.

- `js/reviewEngine.js`: R1/R2/R3 복습 엔진
- `js/patchEngine.js`: n.5 오답 패치 엔진
- `js/rescheduler.js`: 자동 재편성 엔진

## 설계 원칙

- 사용자가 시험범위와 교재를 직접 입력합니다.
- AI는 구조화 보조만 합니다.
- 앱은 입력된 데이터를 바탕으로 태스크를 생성합니다.
- 완료 기준은 “봤다”보다 “수행 가능하다”에 맞추는 것을 권장합니다.
- v0.9는 과집중 방지를 위해 최소 실행판에 집중합니다.
