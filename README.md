# Study Compiler v3.5

시험범위와 교재 버전을 입력하면, 개념별 학습 태스크를 만들고 **D-day 기반 자동 분배 + R1/R2/R3 복습 + n.5 오답 패치 + 자동 재편성 + 월간 캘린더**까지 관리하는 GitHub Pages 호환 정적 웹앱입니다.

## v3.5 핵심 기능

- 과목/시험일 입력
- 시험범위 트리 입력
  - `ㄴ` 개수 또는 들여쓰기로 계층 표현
- 교재 버전 입력
  - 예: `v0: 개념서`, `v1: 기본 유형서`, `v2: 중난도 유형서`, `v3: 심화서`
- 개념 × 버전 태스크 자동 생성
- 시험일까지 남은 날짜를 기준으로 버전별 학습 기간 자동 분배
- 오늘의 빌드 화면
- 이번 주 보기 화면
- 월간 캘린더 보기
- 수행평가 p0~p4 단계 관리
- 수행평가 마감일 주간/캘린더 표시
- 학습 기록 입력
  - 실제 소요 시간
  - 정답률
  - 이해도
  - 메모
- 암기형/혼합형 과목 완료 시 R1/R2/R3 복습 자동 생성
- 정답률/이해도 기준 n.5 오답 패치 생성
- 패치 태스크 우선순위 반영
- 자동 재편성
  - 미완료 태스크 이월
  - 초과 완료 태스크 실제 완료일 반영
  - 남은 날짜 기준 재분배
  - 중요도 낮은 심화 태스크 보류
  - 하루 용량 초과 경고
  - 재빌드 미리보기 → 적용
- localStorage 저장
- AI 설계 프롬프트 생성
- AI JSON 붙여넣기 및 검토/적용
- 백업 내보내기/가져오기

## 기존 데이터 유지

v3.5는 v0.9/v1.5/v2.5와 같은 localStorage 키를 사용합니다.

```txt
study_compiler_v09
```

따라서 같은 브라우저에서 이전 버전을 사용하던 경우, v3.5에서도 기존 과목/태스크/수행평가 데이터가 이어질 수 있습니다.

## 실행 방법

1. ZIP 압축을 풉니다.
2. GitHub Pages에 업로드하거나 로컬 서버로 실행합니다.
3. JS 모듈 구조이므로 파일 더블클릭보다 GitHub Pages/로컬 서버 실행을 권장합니다.

간단 로컬 서버 예시:

```bash
python -m http.server 8000
```

그 후 브라우저에서 `http://localhost:8000` 접속.

## 추천 사용 흐름

1. `과목/범위` 탭에서 과목을 추가합니다.
2. 시험일과 과목 유형을 설정합니다.
3. 시험범위 트리를 입력합니다.
4. 교재 버전을 입력합니다.
5. `태스크 생성/재생성`을 누릅니다.
6. `오늘의 빌드`, `이번 주 보기`, `캘린더`에서 일정을 확인합니다.
7. 실제 시간/정답률/이해도를 입력합니다.
8. 완료 체크를 누르면 조건에 따라 복습/패치가 자동 생성됩니다.
9. 일정이 밀렸거나 과밀하면 `데이터` 탭에서 `재빌드 미리보기`를 확인한 뒤 `재빌드 적용`을 누릅니다.

## 자동 재편성 규칙

- 완료된 태스크가 원래 예정일과 다른 날에 완료되면 실제 완료일로 반영합니다.
- 미완료 태스크는 남은 날짜에 맞춰 다시 배치합니다.
- 패치와 복습은 정규 학습보다 우선 표시됩니다.
- 남은 용량이 부족할 때 낮은 중요도 또는 v3/v4 심화 태스크는 `deferred` 상태로 보류됩니다.
- 적용 전 반드시 미리보기가 표시됩니다.

## 주의

- 자동 재편성은 학습 판단을 완전히 대체하지 않습니다.
- 보류된 태스크는 필요하면 직접 다시 생성하거나 버전을 조정하세요.
- 하루 가능 시간은 과목별 설정입니다. 전과목을 같이 운영하면 캘린더와 용량 경고를 함께 확인하는 것이 좋습니다.
