# Study Compiler v4.2

학교 진도, 시험범위, 요일별 공부 가능 시간, 복습/패치 태스크를 함께 관리해 **시험 7일 전까지 정규 진도를 끝내는 개인용 공부 계획 자동화기**입니다.

## 핵심 개념

Study Compiler v4는 단순히 “시험범위 입력 → D-day 분배”만 하는 앱이 아닙니다.

- **학교 진도 추적**: 영어·국어처럼 시험범위가 늦게 확정되는 과목은 매일 배운 내용을 먼저 기록합니다.
- **시험범위 관리**: 수학·정보처럼 범위가 비교적 명확한 과목은 시험범위 트리와 교재 버전을 기준으로 태스크를 만듭니다.
- **요일 시간표**: 요일별 공부 가능 시간대와 가능한 과목을 지정합니다.
- **정규 진도 마감 버퍼**: 기본값은 시험 7일 전입니다. 이 시점까지 정규 진도를 끝내고 이후에는 복습/패치 중심으로 운영합니다.
- **미배치 허용**: 시간이 부족하면 무리하게 욱여넣지 않고 `unscheduled` 상태와 경고를 표시합니다.

## 추천 과목 설정

| 과목 유형 | 추천 계획 방식 |
|---|---|
| 수학, 정보 | 시험범위 확정형 |
| 영어, 국어 | 학교 진도 추적형 또는 혼합형 |
| 법, 지리 | 혼합형 |

## 주요 사용 흐름

### 1. 과목 만들기

`과목/범위` 탭에서 과목을 추가합니다.

- 시험일 상태: 미정 / 예상 / 확정
- 계획 방식: 시험범위 확정형 / 학교 진도 추적형 / 혼합형
- 정규 진도 마감 버퍼: 기본 7일

### 2. 학교 진도 기록

`학교 진도` 탭에서 오늘 수업에서 배운 내용을 기록합니다.

예:

```txt
과목: 영어
내용: Lesson 4 관계대명사 what
유형: 어법/문법
선생님 강조도: 높음
시험 가능성: 높음
메모: 서술형 가능성 언급
```

학교 진도 기록은 당일 복습, 2일 뒤 재복습, 7일 뒤 회독 태스크로 이어집니다.

### 3. 시험범위 입력

시험범위가 확정된 과목은 `시험범위 트리 입력`에 범위를 입력합니다.

```txt
지수와 로그
ㄴ 지수
ㄴㄴ 거듭제곱근
ㄴㄴ 지수의 성질
ㄴ 로그
ㄴㄴ 로그의 뜻
ㄴㄴ 로그의 성질
```

### 4. 요일 시간표 설정

`요일 시간표` 탭에서 요일별 공부 가능 시간과 가능한 과목을 설정합니다.

- 가능 과목을 비워 두면 전 과목 가능입니다.
- 우선 과목을 지정하면 같은 조건에서 먼저 배치됩니다.

### 5. 계획 확인

`오늘의 빌드`, `이번 주 보기`, `캘린더`에서 배치 결과를 확인합니다.


## v4.2 구조 정리 메모

이번 구조에서는 기존의 큰 `js/ui/events.js`를 기능별 이벤트 모듈로 분리했습니다.

```txt
js/ui/events/
  index.js
  tabEvents.js
  subjectEvents.js
  aiEvents.js
  performanceEvents.js
  dataEvents.js
  scheduleEvents.js
  classProgressEvents.js
  taskEvents.js
  formUtils.js
```

이제 `js/app.js`는 `./ui/events/index.js`에서 이벤트 바인딩을 직접 가져옵니다. 기존 루트의 짧은 re-export 파일들은 정리 대상이어서 새 구조에서는 포함하지 않았습니다.

## 데이터 저장

브라우저 `localStorage` 키는 기존 데이터 유지를 위해 다음 값을 사용합니다.

```txt
study_compiler_v09
```

Supabase 연결은 선택 사항입니다. GitHub Pages 같은 정적 사이트에서는 publishable/anon key가 브라우저에 보일 수 있으므로, 데이터 보호는 Supabase RLS 정책으로 해야 합니다. service role key는 절대 브라우저 코드에 넣지 마세요.

## 실행 방법

JS 모듈을 사용하므로 파일 더블클릭보다 로컬 서버 또는 GitHub Pages 실행을 권장합니다.

```bash
python -m http.server 8000
```

브라우저에서 접속:

```txt
http://localhost:8000
```
